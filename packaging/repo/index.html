rFirma

Firma electrónica nativa para Linux, sin depender de Java.

Alfa

Instala añadiendo un repositorio

Los tres canales de rFirma son repositorios propios, no ficheros sueltos: una vez añadido uno, las actualizaciones llegan solas con el gestor de paquetes de tu sistema.

Todavía no hay ninguna versión publicada. Los repositorios de esta página se están construyendo; hasta que exista la primera Release estas órdenes no van a funcionar. Vuelve cuando rFirma anuncie su primera versión, o sigue el desarrollo en github.com/sgomez/rfirma.

flatpak

Para cualquier distribución de Linux. Se resuelve del remoto propio, no de Flathub.

flatpak install https://rfirma.sgomez.me/rfirma.flatpakref

apt (Debian, Ubuntu y derivadas)

curl -fsSL https://rfirma.sgomez.me/rfirma.asc | sudo tee /usr/share/keyrings/rfirma.asc >/dev/null
sudo tee /etc/apt/sources.list.d/rfirma.sources <<'EOF'
Types: deb
URIs: https://rfirma.sgomez.me/apt/
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/rfirma.asc
EOF
sudo apt update && sudo apt install rfirma

dnf (Fedora y derivadas)

sudo tee /etc/yum.repos.d/rfirma.repo <<'EOF'
[rfirma]
name=rfirma
baseurl=https://rfirma.sgomez.me/rpm/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://rfirma.sgomez.me/rfirma.asc
EOF
sudo dnf install rfirma

Instalar por más de un canal a la vez da aplicaciones independientes, con memorias separadas: ni los documentos recientes, ni la rúbrica, ni las preferencias se comparten. Elige uno solo.

Qué es rFirma

rFirma sustituye la interfaz Swing y el servidor de sockets en Java de AutoFirma por una aplicación nativa (Tauri: Rust + React). La lógica criptográfica pesada —CAdES, PAdES, XAdES y FacturaE— se apoya en el código original de clienteafirma, compilado con GraalVM Native Image, sin que la clave privada salga nunca del sistema operativo.

El código fuente vive en tres repositorios:

  • sgomez/rfirma — la aplicación y el empaquetado.
  • ctt-gob-es/clienteafirma — el motor criptográfico original, del que se consume la lógica de firma.
  • rfirma-native-bridge — el puente FFI entre ambos.

rFirma no es un producto oficial de la Administración. Está en fase alfa: puede fallar y su forma puede cambiar sin aviso.
