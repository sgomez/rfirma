# Badge

```html
<span class="rf-badge rf-badge--primary">Activo</span>
<span class="rf-badge">Software</span>
```

Dos variantes: contorno (por defecto, texto atenuado) y `--primary` (relleno
slate). No hay variantes de éxito/aviso/error — la paleta es
deliberadamente fría y monocroma. Para señalar un error, usa texto explícito
en un `.rf-hint` de `.rf-field--error`, no un color de insignia.

Etiquetas de una o dos palabras. No metas insignias dentro de botones.
